This final project proposal aims to design and build an adaptive tracer study backend system by applying the Waterfall Iterative development model and the Repository Design Pattern architecture. The main design concept focuses on a strict separation between business logic and the data access layer to improve code readability and long-term maintenance. The system is developed using the Laravel framework with Model-View-Controller (MVC) architecture and MySQL database management, adopting a hybrid relational and JSON structure to accommodate dynamic forms and branching logic. The implementation method is carried out in stages, starting from literature study, functional requirement analysis, Unified Modeling Language (UML) and Business Process Model and Notation (BPMN) diagram design, to the coding and unit testing phases.
